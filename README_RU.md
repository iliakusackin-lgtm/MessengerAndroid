# Messenger APK — инструкция на русском

Проект Android открывает существующий мессенджер `http://89.125.121.18` внутри приложения. GitHub Actions собирает APK автоматически; Android Studio не требуется.

## Загрузка на GitHub
1. Скачайте и распакуйте ZIP на компьютере.
2. На GitHub создайте репозиторий, например `MessengerAndroid`.
3. Откройте репозиторий → **Code** → **Add file** → **Upload files**.
4. Откройте распакованную папку и перетащите ВСЁ её содержимое в область загрузки, включая скрытую папку `.github`.
5. Внизу нажмите **Commit changes**.
6. Откройте **Actions** → **Build Messenger APK**. При загрузке файлов сборка запускается автоматически.
7. Дождитесь зелёной галочки. Откройте запуск и в разделе **Artifacts** нажмите `Messenger-APK`.
8. Распакуйте скачанный ZIP. Внутри будет `app-debug.apk`.

## Если сборка не запустилась
Вкладка **Actions** → **Build Messenger APK** → **Run workflow** → зелёная кнопка **Run workflow**.

Важно: сервер использует HTTP, а не HTTPS. Не используйте реальные пароли или конфиденциальные сообщения, пока сервер не переведён на HTTPS.
